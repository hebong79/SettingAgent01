### 2-1. ★ 격자 폐기는 **산술적으로 옳다**
| 방식 | 면 1개당 필요 관측 | 성공률 | 뷰 A 실측(p=0.769) |
|---|---|---|---|

## 4. 밟지 말 것 (21회차 §5 + 22회차 신규)

### 22회차 신규
(A) **`refScore` 는 후보 의존이다** — `baseScore` argmax 후보의 `paint.score`(`bayGrid.ts:682-699`). 커버리지·프레임이 바뀌면 **기준선이 통째로 옮겨간다.** 시뮬 depth 99.31m 가짜 행 / 실카 **차 지붕 몰딩선**이 실제 사례
(B) **`paint.score` 는 칸당 평균이라 길이에 중립적이지 않다** — 짧아지면 평균이 오른다. **진짜 행은 분모 변경에 비트 불변, 가짜만 부푼다.** 단 **짧아짐이 가짜의 전유물은 아니다**(1:1 ci=4·1:2 ci=2 는 짧아지며 진짜로 뒤집혔다)
(C) **정밀도 0 을 액면대로 쓰지 마라** — 실카 정답 라벨이 「보이는 모든 면」이 아니다. `detect_EV3.png` 의 시안 18칸 대부분이 **라벨 안 된 실제 원열** 위. 정밀도는 **하한**
(D) **IoU 0 을 「엉뚱하게 그렸다」로 읽지 마라** — EV5 는 정답 근변선 지지 구간(x≈1030~1470)이 정답 면(x≈20~440)에 **닿지 않는다**(= 거기까지 안 갔다)
(E) **`car.list` 의 `faceSlot`·`presetId` 는 오라클로도 못 쓴다**(§2-6)
(F) **측정 프레임의 촬영 시각을 확인하라** — 리더가 안 보고 야간 가설을 검증 항목으로 올린 전례(§2-4)
