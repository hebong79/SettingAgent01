## V1 ★ B 모드의 G2 = 0.00000 은 진짜인가 → **반증**

### V1-1. B 경로는 실제로 프레임 화소를 쓴다 (코드 추적 + 실측)

`roiAutoFuse.ts:284 detect()` → `detectPaintLines(frame, …)` / `scanSeparators(frame, …)` / `refineSeparators(frame, …)` 로
**후보 근변선과 분리선 코너가 전부 프레임에서 나온다.** `detectBaysWithModel` 의 ① 선별(`bayGrid.ts:472-494`)은 그 후보들을 겨루게 하므로 **프레임 의존이다.**
B 에서 `calib === null` 조기반환(`bayGrid.ts:508`)이 끄는 것은 ②보정·③재적합뿐이고 ①은 그대로 돈다.

실측(프로브, `1:1` 시점 d0, 모드 B):

| 프레임 | 채택 근변선 `[a,b,c]` | phaseM |
|---|---|---|
| v1 d0 | `[0.06751903, 0.99771799, -723.354590]` | 0.31250000 |
| v2 d0 | `[0.06751916, 0.99771798, -723.354778]` | 0.31250000 |

→ **계수가 7번째 자리에서 다르다.** 프레임 독립이면 비트 단위로 같아야 한다. 격자 퇴화 없음.

### V1-3. 면별로도 같은가 → 「거의 같지만 정확히 같지는 않다」. 0.00000 은 반올림 산물

프로브를 소수 6~8자리로 돌린 결과(`1:1`, 모드 B, 변형 ①=③):

| | s1 | s2 | s3 | s4 | s5 | s6 | s7 | 평균 |
|---|---|---|---|---|---|---|---|---|
| v1 | 0.937460 | 0.943533 | 0.949638 | 0.955757 | 0.961892 | 0.968045 | 0.974219 | **0.95579193** |
| v2 | 0.937462 | 0.943534 | 0.949639 | 0.955757 | 0.961891 | 0.968044 | 0.974218 | **0.95579226** |

- **면별로도 6자리에서 값이 갈린다**(s1 +2×10⁻⁶, s5·s6·s7 −1×10⁻⁶). "평균만 우연히 같은" 것도, "프레임 독립"도 아니다.
- **|Δ평균| = 3.3×10⁻⁷.** 도구가 `toFixed(5)` 로 찍고 구현자가 그 5자리 값끼리 뺐기 때문에 `0.00000` 이 나온 것이다. 이 값이 뜻하는 바는 **"0" 이 아니라 "< 5×10⁻⁶"** 이다.
- 같은 로그 안에서 **변형 ④(융합)는 5자리에서도 움직인다**: `1:1` B ④ = v1 0.95908 / v2 **0.95905** (Δ=3×10⁻⁵). 즉 "B 는 IoU 가 한 자리도 움직이지 않는다"는 서술은 구현자 자신의 로그로 이미 반증된다(G2 표가 ③만 봤을 뿐).

### V1-4. 결정적 실험 — 프레임을 진짜로 바꾸면 B 는 무너진다

원본 픽스처는 읽기만 하고, 프로브의 **시점별 프레임 지정** 기능으로 `1:1` 의 d0 자리에 **v1 의 d3 프레임**(같은 프리셋의 다른 디더 = 진짜로 다른 장면)을 넣었다. 나머지 5시점은 v1 그대로.

| 실행 | ① 단일(=③) 면별 IoU | 평균 |
|---|---|---|
| B / v1 원본 | 0.9375 0.9435 0.9496 0.9558 0.9619 0.9680 0.9742 | 0.95579193 |
| B / **d0 ← v1#d3** | 0.2954 0.2879 0.2805 0.2731 0.2659 0.2587 0.1157 | **0.25386842** |

→ **B 는 프레임에 완전히 의존한다.** 채택 근변선이 `c=-723.35` → `-766.99`, quads 7 → 6, 득표 군집이 `6` → `4/2` 로 갈렸다.
`0.00000` 은 "B 가 프레임을 안 본다"가 아니라 **"두 골든 세트가 사실상 같은 프레임이다"** 를 뜻한다.

## V2 ★ C 모드 `2:2` 전 변형 0.00000 → **확정(실제 현상, 버그 아님)**

구현자가 세운 3가지 버그 가설을 전부 실측으로 기각했다(프로브, `2:2` v1):

| 가설 | 실측 | 판정 |
|---|---|---|
| 중앙값 입력에 `null`/NaN 혼입 | 6시점 자가보정 전부 유효: `5.039671 5.041677 4.952616 5.032747 4.994992 5.040211` | **기각** |
| `medianLow` 입력 길이 ≠ 6 | 길이 **6**. 정렬 후 index `floor(5/2)=2` → **5.032747** (로그의 `보정 5.033` 과 일치) | **기각** |
| 공유 지상고가 비현실적(0·음수·15% 밖) → 격자 화면 밖 | 5.0327m = 공칭 5.0 대비 **+0.65%**(게이트 15% 안). 6시점 전부 `quads=4` 정상 생성, 화면 안 | **기각** |

### 진짜 원인 — 득표 동점 해소가 잘못된 대표 시점을 뽑는다

`2:2` 는 **기저 시점 d0 이 원래부터 엉뚱한 행에 latch 한다.** 그래서 **모든 모드에서 ①단일 = 0.00000** 이다(A·A0·B·C 공통, 구현자 표와 일치). ③이 살아나느냐는 **득표 대표 시점이 d0 을 피하느냐**에만 달려 있다.

프로브가 출력한 군집(변형 ③ = tilt 보정 분기):

| 모드 | 군집 | 승자 | 대표 | ③ 평균 |
|---|---|---|---|---|
| A | `{1,3,5}` `{0,4}` `{2}` | `{1,3,5}` (3표) | **d1** | **0.94182** |
| **B**(고정 4.950) | `{1,3,5}` `{0,4}` `{2}` | `{1,3,5}` (3표) | **d1** | **0.93630** |
| **C**(고정 5.0327) | `{0,4}` `{1,5}` `{2}` `{3}` | `{0,4}` (2표) | **d0** | **0.00000** |

> **★ 중요 — 원인은 "고정 지상고" 자체가 아니다.** B 도 고정 지상고 + 보정 OFF 인데 군집이 A 와 **완전히 같고**(`{1,3,5}`) 대표도 d1 이라 0.93630 이 나온다.
> 무너지는 것은 **C 가 고른 특정 값 5.0327m** 뿐이다. 즉 `2:2` 는 지상고를 4.950 → 5.033 으로 1.7% 올리면 시점별 latch 행이 갈리는 **임계 근처 프리셋**이며, 그 갈림이 동점 해소 규칙과 만나 0 으로 떨어진다.

- 고정 지상고(5.0327)가 각 시점의 latch 행을 바꿔 군집이 **3/2/1 → 2/2/1/1 로 파편화**했다.
- 최다 득표가 **2:2 동점**이 되었고, `roiAutoFuse.ts:337` 의 동점 해소 규칙 `Math.min(...a.members) - Math.min(...b.members)`(**최소 인덱스 우선**)가 d0 을 포함한 군집을 뽑았다.
- d0 은 틀린 행 → IoU 0. ④ 융합도 대표 quad 를 앵커로 삼으므로 함께 0 이 된다.
- 미보정 분기도 같은 구조(`{0,1,4}` 3표, 대표 d0) → ② 도 0.

> **한 줄 규명**: `2:2` 의 C = 0.00000 은 지상고 계산 버그가 아니라, **C 가 고른 지상고 5.0327m 에서 시점별 latch 행이 갈려 득표가 2:2 동점이 되었고, "동점 시 최소 인덱스 우선" 규칙이 원래부터 틀린 행에 latch 해 있던 기저 시점 d0 을 대표로 뽑은 결과**다(같은 조건의 B 는 4.950m 에서 군집이 A 와 동일해 무너지지 않는다).
> **수정 대상 코드는 `src/ground/*` 가 아니라 `roiAutoFuse.ts` 의 대표 시점 선택 규칙이며, 이 라운드는 측정 라운드이므로 고치지 않았다**(§금지 준수 — 점수 변경 0줄). 16회차 후보로 올린다: "동점 시 최소 인덱스" 대신 "도색 지지(`paint.near`/`score`) 최대" 로 대표를 고르면 `2:2` C 는 즉시 회복될 가능성이 높다(d1 의 near 0.726 vs d0 0.762 — 지지만으로는 부족하므로 **설계 검토 필요**, 임의 변경 금지).

또한 기록해 둔다 — **이 취약성은 C 고유가 아니다.** A 도 `2:2` 미보정 분기에서 대표가 d0 이라 ② = 0.00000 이다. 즉 `2:2` 는 어떤 모드든 대표 선택이 한 칸만 흔들리면 0 으로 떨어지는 **불안정 프리셋**이다.
