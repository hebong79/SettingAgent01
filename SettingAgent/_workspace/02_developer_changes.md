## 2. 계획과 실제 구현의 차이 — 왜 바꿨는가

설계 §11의 1~7단계를 전부 밟았다. **5번(코너 입력을 검출 결과로 교체)까지 완료했다** — 채점 경로는 수동 근변이 아니라 검출된 코너를 쓴다. 아래는 설계와 달라진 지점과 그 근거(전부 실측)다.

### C-1. `scanSeparators` 신설 — 설계에 없던 검출기 (★ 가장 큰 변경)

설계 Stage A는 전역 Hough(A3)만으로 분리선을 얻는다고 봤다(U4가 "가장 검증이 약한 지점"이라고 예고했다). **실측 결과 전역 Hough 만으로는 성립하지 않는다.**

> 참 깊이 소실점(수동 정본에서 역산)에 **2px 이내로 수렴하는 검출 직선**: 총 250직선 중 프리셋당 **1~7개뿐**
> (1:1 = 4, 1:2 = 7, 2:1 = 11, 2:2 = 9 @ 2px). 차체 모서리 수백 개에 스텁이 묻힌다.

그래서 **전방선을 이미지에서 먼저 얻은 뒤 그 위에서 각도를 훑는 국소 탐색**을 추가했다. 전방선은 이미지 증거이므로 이 시드는 hold-out을 깨지 않는다.

| 검출기 | 참 코너 근방에 후보가 생겼는가 |
|---|---|
| 전역 Hough 만 | 1:1 에서 5/7, 나머지 프리셋은 사실상 실패 |
| **+ 방향탐색** | **1:1 전 7코너 4.0~14.4px · 1:2 5.3~31.0px · 2:1 2.7~19.3px · 2:2 2.6~24.7px** — 전 프리셋 전 코너에 후보 생성 |

대가: 오검출이 함께 늘었다(참 코너 7개 : 피크 58개). 이 오검출을 §C-3의 결합 게이트로 거른다.

### C-2. 능선(얇은 띠) 필터 신설

마스크가 차체 하이라이트로 뒤덮이는 것을 육안 확인했다(범퍼·후드·헤드라이트). 도색선은 **폭이 유한한 띠**, 차체 하이라이트는 **덩어리**라는 형태 차이를 4방향 × 반폭 후보의 "양옆이 모두 어둡다" 판정으로 분리했다. 순수 국소 판정이라 결정론이 유지된다.

### C-3. 소실점·격자 **결합** 탐색 — 설계는 순차였다

설계 B1~B4는 "분리선 클러스터링 → 코너 → 격자 적합"의 순차 구조다. 실측으로 **두 구속을 따로 걸면 전부 통과하는 허위 해가 남는다**:

- **소실점 수렴만**: 차체 모서리는 슬롯과 **같은 3D 방향**이라 함께 수렴한다(그래서 도움이 되기는커녕 구별이 안 된다).
- **등간격만**: 코너 4개는 3자유도 모형에 **항상** 맞는다 — 잡음 교점으로 잔차 0.03~1.7px 짜리 허위 격자가 만들어졌다(실측: index 0..28 의 가짜 미세격자).

그래서 `(전방선 후보) × (소실점 가설)` 을 전수 순회하며 **수렴 + 등간격 + f범위 + 폭편차 + 지상고**를 동시에 요구하도록 바꿨다. 프리셋당 1400~4200개 가설을 평가한다.

### C-4. 베이 개수 제약을 격자 탐색에 넣었다 (선언된 누출 1)

위 허위 격자를 막는 결정타. 인덱스 범위가 N 이내인 최대 창만 남긴다. 베이 개수 N은 정본의 **메타데이터(개수)** 이며 기하가 아니다 — 설계 §3이 선언한 누출 1 그대로다.

### C-5. 소실점 잔차를 **각도가 아니라 px** 로 잰다

각도 잔차는 짧은 스텁을 원리적으로 불리하게 만든다(길이 100px · 중심오차 0.5px → 각오차 0.57°, 즉 허용 각도와 같은 크기). 선분 길이로 정규화한 px 잔차가 서브픽셀 잡음과 직접 비교 가능한 유일한 척도다.

### C-6. `GroundGrid`/`gridToPixelQuads` 를 쓰지 않았다 — **설계 B9 이탈(정직 표기)**

설계 B9는 `GroundGrid` 를 조립해 `gridToPixelQuads` 로 quad를 만들라고 했다. 실제로는 **`GroundModel` 만 조립하고 quad는 `project.ts`(`backprojectToGround`/`projectToPixel`)로 직접 만들었다.**

사유: `gridToPixelQuads` 는 `groundFrameOf(model, panDeg)` 를 요구하고, 그 프레임은 **PTZ pan 보고값이 정확하다**는 가정 위에 서 있다(`groundFrame.ts` 가정 ②). 검출 경로는 이미지 증거만으로 서야 하므로 pan 의존을 들이면 "이미지 증거 경로가 조용히 텔레메트리 경로로 바뀐다"(설계 B6이 폴백을 금지한 것과 같은 이유). **투영 수학은 그대로 `project.ts` 재사용이므로 R4의 실질(신규 투영 수식 0줄)은 지켰다.** `canonicalizeQuad` 도 재사용한다.

### C-7. 서브픽셀 정련 버그 2건 수정 (실측으로 발견)

| 버그 | 증상 | 수정 |
|---|---|---|
| 최근접 표본 | 프로파일이 ±0.5px로 양자화되어 무게중심에 계통오차. 합성 스트라이프 오프셋 **0.56px** | **쌍선형 보간** |
| 잘린 프로파일 채택 | 프레임 경계에서 한쪽이 잘리면 무게중심이 그쪽으로 끌림. 오프셋 **0.91px** | 잘린 프로파일은 **버린다** → 오프셋 **<0.2px** (V1 통과) |

### C-8. `separatorProfileHalfPx` 신설 + **미해결 상충**

분리선은 전방선과 교차하므로 정련 창이 넓고 시작점이 가까우면 프로파일에 **전방선 자신의 도색이 섞여** 코너가 밀린다. 창을 좁히니 합성 장면이 극적으로 좋아졌다.

```
합성 장면:  scanStartPx 6→18, 반폭 14→8
   코너오차  3.34/2.55/2.62/1.77/2.13 px  →  2.34/1.06/0.08/0.97/1.69 px
   quad IoU  0.9396 0.9281 0.9138 0.8931  →  0.9892 0.9959 0.9953 0.9879   ← 목표 달성
```

**그런데 실프레임에서는 정확히 반대다.** 실제 스텁이 30~120px로 짧아 시작점을 밀면 표본 자체가 사라진다:

```
실프레임 1:1 평균 IoU (구현자 스윕)
   start= 6 nms=10 반폭14 → 0.6004   ← 채택(기본값)
   start=10 nms= 8 반폭10 → 0.0449
   start=12 nms= 8 반폭 8 → 0.0026
   start=14 nms= 8 반폭 8 → 0.1223
   start=18 nms= 6 반폭 8 → 0.0229
```

**기본값은 실프레임 최선을 따랐다.** 합성 상한은 `test/bayGeometry.test.ts` 가 튜닝값(`CLEAN_OPTS`)으로 따로 봉인하며, **그 테스트는 "증거가 깨끗하면 기하가 0.98을 낸다"는 상한이지 현장 성능이 아니라고 파일에 명시**했다. 이 상충은 **미해결**이다(§6-U3).

### C-9. `resolveManualAssignment` 의 근/원 모호성 (실측으로 드러남)

이미지측 일관성만으로는 **근변 행과 원변 행을 구분할 수 없다** — 두 행 모두 사영 등간격이고, 둘을 잇는 분리변은 같은 소실점으로 수렴한다. 저작 rot=1에 대해 복원 rot=3(근변 파싱)과 rot=1(원변 파싱)이 **둘 다 수학적으로 정답**이며 잔차가 동점이다. 근/원 구분은 이미지가 아니라 "카메라에 가까운 쪽"이라는 외부 규약이 정한다. 테스트에 그대로 기록했고, 기하는 오염되지 않으므로 채점에는 영향이 없다.

## 10. ★ 반증된 가설 — 다시 시도하지 말 것

구현자가 실제로 코드를 바꿔 돌려 보고 **되돌린** 항목이다. 근거가 그럴듯했으므로 다음 라운드가 같은 함정에 빠지지 않게 남긴다.

**가설:** "이미지 추정 지상고는 독립 검증량이고 틀린 가설은 20%+ 벗어나므로, 지상고 편차를 가설 선택의 1순위 정렬 키로 쓰면 옳은 가설이 뽑힌다."

**실험:** `detectBays` 의 정렬을 `지상고편차(5% 버킷) → 코너수 → 격자잔차` 로 바꿔 전 프리셋 재측정.

**결과 — 반증:**

| key | 지상고(변경 전 → 후) | 1:1 평균 IoU |
|---|---|---|
| 1:1 | 3.844m(23.1% 이탈) → **5.188m(3.8%)** | **0.6004 → 0.0049** |
| 1:2 | 3.860m(22.8%) → **4.991m(0.2%)** | 0.0000 → 0.0000 |
| 2:1 | 4.731m(5.4%) → **4.984m(0.3%)** | 0.0000 → 0.0000 |
| 2:2 | 5.081m(1.6%) → 5.081m(1.6%) | 0.0000 → 0.0000 |

지상고는 전 프리셋에서 4% 이내로 **맞았는데 IoU 는 붕괴했다.**

**해석:** 지상고 일치는 옳은 가설의 **필요조건일 뿐 충분조건이 아니다.** 틀렸지만 자기일관된 기하(엉뚱한 직선들이 우연히 소실점·등간격·직교 구속을 모두 만족)도 지상고를 맞춘다. 이 신호를 선별의 주키로 쓰면 "물리적으로 그럴듯하지만 엉뚱한 곳에 놓인" 격자를 선호하게 된다. **경고(D6)·tie-break 로만 써야 한다.** 코드 주석에도 이 사실을 남겼다(`bayGeometry.ts` 정렬부).

**파생 교훈:** 남은 구속들(소실점 수렴·등간격·f 범위·폭편차·지상고)은 전부 **격자 자체의 내부 일관성**만 본다. 어느 것도 "그 격자가 이미지의 도색 증거를 실제로 덮는가"를 묻지 않는다. **재투영 검증이 빠져 있다** — 다음 라운드 1순위 후보다.
