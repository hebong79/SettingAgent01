### 1-2. `roiAutoFuse.ts` 구현 노트

```

  frames : v1(기본) | v2 | <디렉터리 경로>
  modes  : A(기본) | CSV 예 "A,A0,B,C"
```

- **하위호환**: 모드가 1개면 접두(`[A ]`)·모드 배너를 붙이지 않아 14회차와 **바이트 동일** 출력이 나온다(§5 검증 2-2).

- **B 는 플래그만으로 성립하지 않는다**(계획 §Q2 부수발견 그대로 확인): 정본 `camera.position[1] = 5.0` 이라 `calibrateHeight:false` 만 주면 5.000m 가 쓰인다. `PresetIntrinsics.heightM = 4.950` 오버라이드를 **함께** 적용했다(상수 `F6_HEIGHT_M`).
- **C 는 2-pass**: pass1 = A 모드 결과 재사용(추가 검출 0회) → `medianLow`(짝수면 낮은 쪽, R2) → pass2 = `heightM` 고정 + `calibrateHeight:false`. **미보정/보정 두 분기가 각자의 6시점에서 따로 중앙값을 낸다**(값이 실제로 갈린다 — 예 `2:1` 4.995 vs 5.019).
- **기저 모델 `m0` 는 전 모드 공칭 5.0 고정.** 재투영은 `d` 에 대해 스케일 불변이므로 이것이 좌표계를 모드 간 통일한다.
- **표본 0건 방어**: 자가보정이 6시점 전부 거부되면 C 를 산출하지 않고 `미산출(자가보정 표본 0/6)` 로 출력한다. 이번 실행에서는 발동하지 않았다.

## 8. 14회차 `CALIB=0` 수치의 교락 정정 (설계자 §0 확인)

## 10. 실패·미측정·주의 항목 (은닉 없음)

1. **기준 ① 의 `2:1` 측정은 성립하지 않았다.** v2 가 v1 과 같은 프레임을 잡았다. 대체로 `1:1`·`1:2` 를 썼고, 그 사실을 위 §0·§6 에 명시했다. **보간·추정으로 채우지 않았다.**
2. **v2 는 "정착 프레임"이지만 v1 과의 차이는 정착 때문이 아니다.** `attempts=2`(즉시 정지)가 30/30 이다. 두 세트의 차이는 캡처 시각의 씬 상태다. "v1=이동직후 / v2=정착본" 서술은 이 실측으로 지지되지 않는다.
3. **모드 C 는 `2:2` 에서 전면 붕괴한다** — v1·v2 모두 ①②③④ 전부 **0.00000**(4면). 고정 지상고(5.040/5.033) + 보정 OFF 조합에서 `2:2` 의 격자 선별이 다른 행으로 넘어간 것으로 보인다(득표가 A 의 `3/2/1` → `3/1/1/1`·`2/2/1/1` 로 분산). **원인은 이번 라운드에서 추적하지 않았다**(측정 라운드 범위 밖).
4. **모드 B 는 `2:2` 에서 ③ 0/4(0.93630)** — A/A0 의 2/4 대비 2면 감소. v1·v2 동일.
5. **B/C 의 v1 전체 ≥0.95 는 A 보다 낮다**(B 4면 · C 9면 vs A 13면). v2 에서만 역전된다(B 4 · C 5 vs A 3). **즉 B·C 의 이점은 "점수"가 아니라 "프레임 무관성"이다.**
6. **B+/C+ (도구 레벨 ③ 재현) 미착수** — 리더 판정 Q-c 대로 착수 금지. 16회차 후보로만 남긴다.
7. **`bayGrid.ts:508` 무수정** — 리더 판정 Q-d 대로 보고만. 16회차 후보: "`calib === null` 이어도 ③ 재적합으로 진행하도록 조기반환을 완화" → 이것이 되면 "고정 지상고 + 재적합 ON"(B+/C+)이 서비스 경로에서 성립한다.
8. **`1:3` 은 여전히 `graded:false` 구간**(2면, 상한 기여 0). 어떤 모드에서도 0.16 대다.
9. **런타임**: v1·v2 각 4모드 = 프리셋당 최대 48 detect. 두 실행 병렬로 벽시계 **약 47분**.
