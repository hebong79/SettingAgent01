## 1. V1 독립 재확인 — 「검출」이 카메라를 움직이는가

구현자 보고와 **별개로** 리더가 직접 쟀다. 임의 뷰(pan 60)에서:

```
검출 전 : {"pan": 60.0000038, "tilt": 14.0,      "zoom": 1.3}
검출 후 : {"pan": 60.0000038, "tilt": 14.000001, "zoom": 1.3}
```

- **tilt 만 1 float32 ULP 이동**(1.907e-6°). 구현자가 보고한 "첫 1회만"과 일치한다.
- **2회차 호출부터 고정점**임을 확인(같은 값 반복 → 불변).
- 광학적 의미 f 2251px 에서 **9.1e-5px**. 물리 이동이 아니다.
- 대조군 `view:"preset"` 은 `{41.5, 20.1, 1.58}` → `{90.1, 35.8, 1.0}` 로 **실제로 움직인다**(전제 성립).

**판정: V1 PASS.** 단 "안 움직인다"고 주장하는 모드가 미세 이동을 조용히 삼키면 안 되므로
**응답 `issues` 에 노출하라고 지시**했다(3차 이터레이션에 반영됨).

> 설계서 §7 의 V1 스크립트는 `curl` 의 `id` 를 1/3 로 다르게 준 채 응답 전문을 diff 해서

## 3. ★ 오버레이 육안 판정 — 리더가 직접 본 것

`reports/overlay_r20/_crop_As4.png` · `_crop_As8.png`. **같은 프레임 · 같은 PTZ · `expectedBays` 만 4→8.**

| | bays=4 | bays=8 |
|---|---|---|
| 검출 위치 | 빨강이 **초록(정답) 위에 얹힘** | 주황이 **행 방향으로 반칸 밀림** |
| r2f1~r2f6 IoU | 0.96 / 0.96 / 0.94 / 0.91 / 0.92 / 0.94 | 0.33 / 0.36 / 0.37 / 0.38 / 0.39 / 0.40 |

**리더 판정: ③ 격자 위상(lattice phase) 반칸 어긋남.**
- 정답 투영 결함이 아니다 — 초록은 두 장에서 **같은 자리**이고 도색선 위에 얹혀 있다.
- 검출 실패도 아니다 — 같은 6면을 같은 행·같은 깊이에서 찾았다. **행 방향 위상만 틀렸다.**
- bays=8 의 IoU 6개가 전부 **매칭 문턱 0.5 바로 아래**(0.33~0.40)에 깔린 것이 결정적이다.
  "못 찾은 것"이 아니라 "조금 어긋나 매칭에서 탈락한 것"이다.

**따라서 재현율 0 은 검출 능력의 한계가 아니다.** 진단이 완전히 달라진다.

## 4. 이 발견의 무게 (리더 판단)

구현자 실측에 따르면 **정답 위상의 도색 지지 점수(1.5766)가 실제로 선택된 위상(1.4821)보다 높다.**
증거는 정답을 가리키는데 **선택이 졌다.** 증거 결함이 아니라 **선택 결함**이다.

그리고 `IoU = (1−φ)/(1+φ)` 관계가 성립한다면(구현자 측정), **위상만 바로잡히면 IoU 는 0.93~0.96 으로 올라간다.**
마스터 목표②(IoU ≥0.95)가 검출 알고리즘 개선이 아니라 **선택 결함 수정만으로** 풀린다는 뜻이다.

7회차의 "결손 전체가 근변선 오프셋 단일 성분"은 **cross 방향**이었다. 이건 **along 방향**이므로 **별개 성분**이다.
반증목록 20건에도 위상 선택 항목은 없다.

→ 리더는 3차 이터레이션(위상 후보 점수표 노출)을 열었고, **G1~G5 게이트**를 걸어 조건부 수정을 승인했다.
   특히 **G3**(골든 v1 rows 의 재현율·정밀도·IoU 셋 다 개선 또는 동일)를 못 넘기면 배선 금지다.

## 4-B. QA 의 「테스트 10건 삭제」 지적 — 리더 추적 결과 **오탐**(다만 유익한 오탐)

**결론**
- 20회차는 테스트를 **하나도 삭제하지 않았다.**
- 리더 인계서의 "287파일 **3661**"은 **패널 제거 이전** 값이었고, 구현자가 실측한 **3651** 이 착수 시점의 옳은 기준선이다.
  구현자의 "지시서 숫자가 실제와 다르다"는 지적은 **맞았다**(원인 귀속만 없었다).

  이 방법이 없었으면 −10 을 아무도 못 봤다. 귀속만 리더가 채웠다.

**유익한 오탐인 이유**: 이번 세션에 **서로 모르는 두 작업이 같은 파일(`web/index.html`·`app.css`)을 건드렸다**.
