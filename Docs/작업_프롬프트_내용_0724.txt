정밀수집페이지의 시작 버튼을 누르면 
1. 전체 주차면 슬롯을  "육면체 앞면 중심 LOOP"로 LPD 검지한다. 1개 슬롯 검지후 약 0.5초 대기한다.
2. LPD로 번호판을 검지하면 점유영역을 만든다. 생성후  0.3초 대기
3. LPD, 점유영역 생성이 완료된후 1초 대기
4. 전체주차면의 번호판을 중심으로 센터라이징을 한다. ( pan/tilt 중심이동 -> zoom )
5. zoom을 할때 번호판 가로크기의 20%까지 확대, 
  ( 18% ~ 25% 여유, 만약 36배줌인데 18% 미만이어도 그상태에서 멈추고 ptz 보관 )
6. 1개 주차면 센터라이징 끝나고 1초 대기 
7. 모든 센터라이징이 끝나면 setup_result.json 파일 생성
8. 완료 메세지 출력  
9. 최종화 누르면 화면에 LPD, 점유영역, 센터라이징 위치(작은노란색 원) 출력해주기
10. 여기의 모든 기능은 기존에 만들어진 함수를 가져다만 사용한다. (중요)
11. 만약 함수가 없다면 기존 기능을 매핑한 함수만 만든다.
12. 이전 바닥 LLM 사용 콤보박스 제거, 완료후 자동 최종화 체크 박스 제거, 
13. 정밀수집 시작은 리얼카메라와 시뮬레이터 분리하여 사용. 기준은 시뮬레이터 임.

이내용으로 설계서를 만들어줘.
