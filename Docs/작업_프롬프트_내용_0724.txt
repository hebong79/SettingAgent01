[7/28]----------------------------
카메라 출력화면 위에 ROI 를 수등으로 그리는 UI를 만들려고한다.(ROIMaker) 
1. 새로운 페이지를 만들어서 사용한다
2. 마우스를 클릭하여 점을 만들고(출력) 두번째 클릭하면 점이 생성되고 라인이 그려진다.
3. 이렇게 기본은 4개의 점으로 마무리 하고 5개 이상도 가능하다.
4. ROI 라인그리기를 마무리 할때는 마우스 오른쪽 버튼을 누르면 사각형(또는 다각형)이 그려진다.
5. 선택된 카메라의 선택된 프리셋의 주차면 이다( 주차면 슬롯 ). 
 - 전체 슬롯 리스트 UI가 존재해야 한다.
6. 기존에 존재하는 ROI가 있으면 화면에 출력 되어야 한다.
7. 기존 그려진 ROI는 수정이 가능해야 한다. ( 마우스로 점 클릭후 드래그 )
8. 시작 버튼을 눌러서 시작 플래그가 활성화 되면 그리기 시작한다.
9. 시작 버튼은 토글처럼 색상이 변경되고 버튼 텍스트가 정지로 변경되고,
10. 다시 그버튼(정지)을 누르면 그리기 작업이 정지 된다. 
11. 9번, 10번이 없어도 가능하면 없어도 된다.
12. 저장 버튼을 누르면 DB에 저장하고 UI에도 변경되어야 한다.

[7/22]----------------------------
정밀수집페이지의 시작 버튼을 누르면 
1. 전체 주차면 슬롯을  "육면체 앞면 중심 LOOP"로 LPD 검지한다. 1개 슬롯 검지후 약 0.5초 대기한다.
2. LPD로 번호판을 검지하면 점유영역을 만든다. 생성후  0.3초 대기
3. LPD, 점유영역 생성이 완료된후 1초 대기
4. 전체주차면의 번호판을 중심으로 센터라이징을 한다. ( pan/tilt 중심이동 -> zoom )
5. zoom을 할때 번호판 가로크기의 20%까지 확대, 
  ( 18% ~ 25% 여유, 만약 36배줌인데 18% 미만이어도 그상태에서 멈추고 ptz 보관 )
6. 1개 주차면 센터라이징 끝나고 1초 대기 
7. 모든 센터라이징이 끝나면 setup_result.json 파일 생성
8. 완료 메세지 출력  
9. 최종화 누르면 화면에 LPD, 점유영역, 센터라이징 위치(작은노란색 원) 출력해주기
10. 여기의 모든 기능은 기존에 만들어진 함수를 가져다만 사용한다. (중요)
11. 만약 함수가 없다면 기존 기능을 매핑한 함수만 만든다.
12. 이전 바닥 LLM 사용 콤보박스 제거, 완료후 자동 최종화 체크 박스 제거, 
13. 정밀수집 시작은 리얼카메라와 시뮬레이터 분리하여 사용. 기준은 시뮬레이터 임.

이내용으로 설계서를 만들어줘.
